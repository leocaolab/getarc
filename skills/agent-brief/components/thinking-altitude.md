# 先退一步看整体

- **系统是几个状态机。** 值在它们之间流动、变形: 在一处产生, 被另一处据以做决定, 被暂存, 最后落在某个输出里。在边界上, 一个值会展开 (unfold) 成几方各自的值; 几方的值会折叠 (fold) 成一个输出。
- **动手之前, 退一步, 从高处看。** 在 `model.md` 里写下: 有哪些状态机、各有哪些状态; 每个相关的值从产生到落下的路径 —— 谁产生、经过哪里、在哪里展开、在哪里折叠、最后落在哪里; 你要写的部分在这张图上的位置: 它收到什么、发出什么、不碰什么。
- **照着这张图写代码。** 写完回到高处再看一遍: 代码里的每个类型、每个判断, 都在图上找得到它的位置吗? 找不到的, 要么图漏了, 要么它不该存在。
