# 形式化提示

动手之前, 把要写的部分当成一个形式化的系统写下来 (写在 `spec.md`, 不必是哪种工具的语法):

- **状态**: 每个状态变量和它的取值集合。
- **事件**: 能让状态变化的每一种输入, 谁发出。
- **转移**: 对每个 (状态, 事件), 下一个状态和发出的效应; 每一格都要填, 没有"不可能"的格子 —— 真不可能的, 让状态的类型表达不出来。
- **不变量**: 每一步转移之后都成立的性质; 每条写明由哪个转移维持。
- **活性**: 最终一定会发生的事 (例如: 交上来的每一项最终有一个结局)。

然后让代码一一对应: 状态 → 类型, 转移 → 一个纯函数, 不变量 → 测试 (边界两侧各一个)。
