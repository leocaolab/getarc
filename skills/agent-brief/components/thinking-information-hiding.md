# 信息隐藏与负能力

- **一个模块藏一个决定。** 找出这个程序里可能变化、或者只有一方该知道的那些决定; 每个决定由一个模块拥有, 别的模块只通过它的接口拿到结果。
- **每个模块写两栏: 它知道什么、决定什么; 它不知道什么、不决定什么、不等什么。** 第二栏和第一栏一样重要。一个模块开始知道它本不该知道的东西, 就是边界漏了。
- **边界上只越过该越过的。** 两个模块之间传的, 是一方的结果, 不是一方的内部; 一个接口没有给你的东西, 不是障碍, 是边界 —— 不要为了拿到它去拆别人的接口。
- **漏了不打补丁。** 一个修法如果需要让某个模块开始知道别人的事、或者需要新的状态和兜底分支才站得住, 说明东西放错了地方: 把它送回拥有它的那个模块。

动手之前, 在 `model.md` 里为每个模块写下这两栏和它们之间越过的东西, 然后照着写代码。
